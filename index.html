🔑 Gmail API Setup Guide
This tool uses Google's official Gmail API. Your emails are sent directly from your Gmail account via Google's servers. No passwords are stored here — only a temporary access token.
1
Go to Google Cloud Console
Open console.cloud.google.com → Sign in with your Gmail account → Create a new project (e.g., "JobTracker")
2
Enable Gmail API
Go to APIs & Services → Library → Search for "Gmail API" → Click Enable
3
Create OAuth 2.0 Credentials
Go to APIs & Services → Credentials → Create Credentials → OAuth Client ID → Application type: Web application → Add Authorized JavaScript Origin: null (for local HTML file) or your domain → Download the JSON and copy the Client ID
4
Configure OAuth Consent Screen
Go to OAuth consent screen → External → Fill in App name → Add your Gmail under Test users → Save
5
Enter Your Client ID Below
Paste your OAuth Client ID (ends in .apps.googleusercontent.com)
