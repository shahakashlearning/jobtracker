📖 What each button does:
🔥 Connect Firebase
Connects this browser to your Firebase database. Run this once per device after importing config file. After connecting, realtime listeners activate — any change on any device appears everywhere within 1 second automatically.
🔄 Sync Now
Pulls latest data from cloud → into this browser. Use this if you feel data is out of date. Not normally needed — realtime listeners do this automatically.
⬆️ Push Local Data
One-time migration only. Use this to upload data that was saved in this browser BEFORE Firebase was connected (like your existing 2 HR contacts in Edge). After this, all future saves go to cloud automatically — you never need this button again.
🔥Step 1 — Connect Firebase Cloud Database
⚠️ Why your data isn't syncing: Firebase is not connected yet. Data saved in Edge stays in Edge only. Once you connect Firebase below, ALL devices will share the same data automatically.
Firebase free tier = 50,000 reads + 20,000 writes per day. Free forever. No credit card needed.
📋 How to get your Firebase config file (one-time setup)
1
Create Firebase project
Go to console.firebase.google.com → Click Add project → Name: JobTracker → Disable Analytics → Click Create project
2
Create Firestore Database
Left sidebar → Build → Firestore Database → Create database → Select "Start in test mode" → Choose asia-south1 (Mumbai) → Enable
3
Register a Web App & download config
Left sidebar → Click ⚙️ Project Settings (gear icon) → Scroll down to "Your apps" → Click </> Web icon → App nickname: JobTracker → Click Register app

You will see a firebaseConfig object. Below it, click "Continue to console".

Now: Click the three dots ⋮ next to your app → Download google-services.json — OR simply copy the config values shown on screen.
4
Create a simple config file on your computer
Open Notepad → paste the template below with your values → Save as jobtracker-config.json
{
  "apiKey": "AIzaSy...",
  "authDomain": "jobtracker-xxx.firebaseapp.com",
  "projectId": "jobtracker-xxx",
  "storageBucket": "jobtracker-xxx.appspot.com",
  "messagingSenderId": "123456789",
  "appId": "1:xxx:web:xxx",
  "gmailClientId": "xxxxxxxx.apps.googleusercontent.com"
}
The gmailClientId field is optional — if included, Gmail is also auto-configured when you import this file.
📂 Import your config file
Select your jobtracker-config.json file — all fields fill automatically
▶ Or enter details manually (advanced)
📧Step 2 — Connect Gmail
If you included gmailClientId in your config file above, this is already filled in. Just click Connect Gmail.
🔒Fix Firestore Rules (Required for sync to work)
⚠️ This is the #1 reason data does not sync. Firestore "test mode" rules expire after 30 days and block all reads/writes. You must update the rules to allow access permanently.
Do this one time in Firebase Console:
1
Open Firestore Rules
Go to console.firebase.google.com → Your project (JobTracker) → Left sidebar → Firestore Database → Click the Rules tab at the top
2
Replace ALL the existing rules with this
Select all existing text in the rules editor and replace with:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
3
Click Publish
Click the blue Publish button in Firebase. Rules take effect within 60 seconds. Then come back here and click Push Local Data to Cloud.
💡 allow read, write: if true means only people who have your Firebase config (stored in your private config file) can access the data. This is safe for personal use.
