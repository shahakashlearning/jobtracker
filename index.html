📖 What each button does:
🔥 Connect Firebase
Connects this browser to your Firebase database. Run this once per device after importing config file. After connecting, realtime listeners activate — any change on any device appears everywhere within 1 second automatically.
🔄 Sync Now
Pulls latest data from cloud → into this browser. Use this if you feel data is out of date. Not normally needed — realtime listeners do this automatically.
⬆️ Push Local Data
One-time migration only. Use this to upload data that was saved in this browser BEFORE Firebase was connected (like your existing 2 HR contacts in Edge). After this, all future saves go to cloud automatically — you never need this button again.

🌐Fix Firebase Authorized Domains (PRIMARY fix — do this first)
This is the #1 root cause of the "Uploading..." stuck button and all sync failures.
Firebase blocks all Firestore requests from domains not listed in its Authorized Domains. Your domain shahakashlearning.github.io must be added there.
1
Open Firebase Console → Authentication → Settings
Go to console.firebase.google.com → Your JobTracker project → Left sidebar → Build → Authentication → Click the Settings tab at the top
2
Add your domain to Authorized Domains
You will see an "Authorized domains" section with a list. Click "Add domain" and add:
shahakashlearning.github.io
3
Click Add → then come back here and test
After adding, come back here → click "Connect Firebase" → you will see ✅ Write access confirmed within 5 seconds. Then click "Push Local Data to Cloud" — it will complete instantly.
⚠️ If Authentication is not enabled in your Firebase project: Left sidebar → Build → Authentication → Click "Get started" → Enable Email/Password provider → then go to Settings tab to find Authorized Domains.
🔒Fix Firestore Rules (Required for sync to work)
⚠️ This is the #1 reason data does not sync. Firestore "test mode" rules expire after 30 days and block all reads/writes. You must update the rules to allow access permanently.
Do this one time in Firebase Console:
1
Open Firestore Rules
Go to console.firebase.google.com → Your project (JobTracker) → Left sidebar → Firestore Database → Click the Rules tab at the top
2
Replace ALL the existing rules with this
Select all existing text in the rules editor and replace with:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
3
Click Publish
Click the blue Publish button in Firebase. Rules take effect within 60 seconds. Then come back here and click Push Local Data to Cloud.
💡 allow read, write: if true means only people who have your Firebase config (stored in your private config file) can access the data. This is safe for personal use.
